# Changes from the latest shared scripts

## Preserved

- Public model/SDE/dataset names and alpha/beta/sigma names.
- Rank-one mixing A_f=1 h_f^T and original unnormalized eigenbasis with H1 pivot.
- Integrated nonzero mode log(lambda)(1-exp(-alpha*t)), null mode -beta*t.
- Instantaneous drift includes the necessary alpha factor.
- B=gV and S=V diag(s), including the phase exp(i Im(phi)) from the last SDE.
- Physical-score DSM residual S^H score + epsilon; no silent whitening switch.
- Enhanced U-Net with fixed sinusoidal frequencies, trainable FiLM, two blocks
  per resolution, dilations, bottleneck attention, and log-magnitude inputs.
- Latent sources as targets, full time convolution, train/cv/test split names.
- Euler/Heun PF dynamics; reverse-SDE predictor and Langevin corrector; stop at eps.

## Explicit correctness fixes

1. **Mismatch branch input centering.** The last provided module computed a
   shifted target but evaluated score(mu_T+S_T*eps). The intended recentered
   augmentation needs score(y_rep+S_T*eps). Default `terminal` implements it;
   `forward_legacy` retains the previous input choice as a named experiment.
   The residual and parameter name `mismatch_probability` are unchanged.
2. **EMA mode/update.** EMA always stays in eval mode, including when parent
   training is enabled. It is updated by an actual optimizer post-step hook;
   accumulation-only batches and skipped optimizer updates do not advance it.
   Frozen time embeddings/buffers are copied, never averaged into trainable state.
3. **FFT parity.** ScoreUNet receives n_fft; only DC and an existing even-length
   Nyquist bin have imaginary output masked. Masking is out of place.
4. **Physical endpoint validation.** Principal-log interpolation may be complex
   even at a real endpoint if sum(H) is negative. The physical-rFFT pipeline now
   rejects that unsupported case rather than silently discarding an imaginary mean.
5. **Metadata and checkpoint restoration.** Entire SDE/network/FFT configs and
   kernels accompany new checkpoints. Evaluation cannot silently change alpha,
   beta or kernels. Unrestricted pickle requires explicit trust.
6. **Silent-input metrics.** The earlier SI-SDR eps/eps implementation returned
   0 dB for an all-zero estimate. The metric now reports a finite very poor score
   in that edge case and rejects silent references. Normal nondegenerate inputs
   use the same ordered-source SI-SDR definition.
7. **Cached data consistency.** Convolutions and cached FFTs derive from the
   stored float32 arrays. The source/filter families and parameter ranges stay
   the same; tiny numerical differences from pre-rounding float64 convolutions
   are possible. Exact old dataset bytes are not regenerated by this refactor.

## Modularization and deliberate experiment options

- Structured per-frequency operator applications replace global/batched dense
  products during training/sampling. Dense `A`, `eigvecs`, `_cov`, and
  `marginal_prob` remain available for old small tests, lazily constructed.
- Covariance quadrature uses a stable difference-of-exponents integrand. The
  repeated null-mode variance uses its exact scalar formula, rather than
  recomputing a trapezoid integral for every null mode. This is mathematically
  equivalent, not guaranteed bitwise-identical to the previous quadrature.
- Original eigenvector normalization and H1 pivot are NOT changed: altering
  eigenvectors changes B=gV and therefore would change the stochastic model.
- `none` and `instantaneous` are explicit drift ablations. In the instantaneous
  ablation the physical B=gV is held fixed and the covariance is computed in
  frequency blocks; incorrectly reusing a diagonal modal variance is avoided.
- `basic` is a lighter controlled network with the same fixed-time embedding,
  not a renamed claim to reproduce every older network checkpoint.
- Corrector max-step cap defaults to 1.0 and is logged; set to null to reproduce
  the old uncapped adaptive step. A zero-score adaptive corrector is skipped
  rather than generating an enormous step through division by a tiny norm.
- No mandatory augmentation, different loss parameterization, data-normalizing
  trick, denoising endpoint, permutation matching, or real-data claim was added.
- No alpha/beta tuning recommendation is inferred from earlier failed pilot runs.

## Reproducibility corrections

- NPZ handles close before worker creation; each member is loaded once.
- Validation uses fixed generators independent of training RNG and uniform time
  weighting for all training-time sampling strategies.
- Configs/filters/training budget/code fingerprints identify experiments.
- Checkpoint and code changes invalidate cached evaluation identities.
- No stale short training checkpoint is silently reused as a longer run.
- Existing output directories require explicit resume/overwrite intent.
- Fixed example IDs seed initial sampling noise, and initial-state hashes are saved.
